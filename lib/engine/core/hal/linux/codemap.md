# lib/engine/core/hal/linux

## Responsibility
The Linux HAL wraps POSIX/glibc + raw-syscall APIs to provide core OS abstractions: page-based memory management via mmap/munmap/mprotect with Windows-matching over-alignment, dual-mapped magic ring buffers via memfd_create, async file IO via a raw-syscall io_uring backend, directory watching via inotify, process creation via fork+execvp, high-resolution timers via timer_create/timer_settime, debugger integration (SIGTRAP, write to stderr, thread IDs via `syscall(SYS_gettid)`), UTF-8/ASCII/char transcoding, `random_device`-seeded RNG, and memory-mapped file support. It implements the pP::hal interface defined in Core.HAL.cppm for the Linux platform, using sysconf(_SC_PAGESIZE) for page size and file descriptors for all I/O operations.

## Design
Each functional area is partitioned into its own `Core.HAL.linux.<Area>.cpp` file. Namespaces mirror the Core.HAL.cppm structure: `pP::hal`, `pP::hal::io`, `pP::hal::process`, `pP::hal::timer`. File descriptors (`int`) are managed with close-on-exec (`INIT1_IN_CLOEXEC`) and RAII-style cleanup via `::close`. Memory uses `MAP_PRIVATE | MAP_ANONYMOUS` with `mprotect` for protection changes; `pageAlloc` matches Windows alignment behavior (fast path when `align <= granularity`, else reserve `aligned_size + align - granularity` as `PROT_NONE`, `mprotect` the aligned slice, `munmap` the head/tail slop). The ring buffer (`RingBuffer.cpp`) builds the magic window with `syscall(SYS_memfd_create, MFD_CLOEXEC)` + `ftruncate` + a `PROT_NONE` 2x reservation overlaid by two `MAP_SHARED|MAP_FIXED` views; `Random.cpp` seeds `mt19937_64` from `random_device` via `seed_seq` (mirrors the Windows RNG file). Io (`Io.cpp`) is a raw-syscall io_uring backend with no liburing dependency: `IoHandleData` holds `ring_fd/eventfd`, SQ/CQ ring mappings (`SINGLE_MMAP`-aware), SQE mapping, `io_uring_params`, and a mutex; `FileHandleData` links the fd back to its `IoHandleData` for cancel. Helpers use `__ATOMIC_ACQUIRE/RELEASE` head/tail accessors, `allocSqeLocked_`/`commitSqeLocked_`, `drainLocked_` (CQE → `CompletionEntry` with `bytes_transferred` vs `-res` error, CQ head advance, eventfd drain, no user callback), and `stashUserData_`/`loadStashedUserData_` (request identity in the caller's overlapped slot for `cancelIo`). Directory watching uses `inotify_init1` + `inotify_add_watch` with `poll` on the fd. Timers use `timer_create` with `SIGEV_THREAD` and a `std23::move_only_function<void()>` callback (via `:function.ref`). Debugger has no `native::char_t` overload (on POSIX it would redefine the `char` overload) and writes to `STDERR_FILENO`. Transcoding is pure C++ plus the shared `string_view → char*` memcpy overload.

## Flow
A typical call flows: `pP::hal::pageAlloc(size, commit, protection, alignment)` → assert `align % granularity == 0` → fast-path `mmap` when `align <= granularity`, else reserve/mprotect/trim-slop over-aligned path → if `!commit`, `madvise(ptr, size, MADV_DONTNEED)`; `pageProtect` calls `mprotect(ptr, size, prot)`; `pageFree` calls `munmap(ptr, size)`; `ringBufferAlloc(buffer_size)` → `memfd_create` + `ftruncate(buffer_size)` + `mmap(PROT_NONE, 2x)` reservation + two `MAP_FIXED` shared views, `close(fd)`, return first view; `ringBufferFree` → `munmap(ptr, 2 * buffer_size)`; `io::init` → `io_uring_setup(256)` + SQ/CQ/SQE mmaps + `eventfd` registered via `io_uring_register(EVENTFD)`; `openFile` → `::open(O_CLOEXEC|O_RDONLY/O_RDWR|O_CREAT|O_TRUNC)`; `submit` → lock, map each entry to `IORING_OP_READ/WRITE` SQE (`fd/addr/len/off/user_data`), flush via `io_uring_enter` and retry once on SQ-full, `enterSubmit_` outside the lock; `poll` → `drainLocked_` under lock; `wait` → loop drain-under-lock then `io_uring_enter(GETEVENTS)` without holding the mutex so `submit`/`wake` can post; `wake` → `IORING_OP_NOP` SQE + `eventfd` write; `cancelIo` → `IORING_OP_ASYNC_CANCEL` SQE addressed by the stashed overlapped `user_data`; `deinit` → lock+drain CQEs into a sink, close `eventfd`/`ring_fd`, unmap SQEs/rings (single-mmap aware), `delete` (noexcept, best effort); `openWatch` calls `inotify_init1(IN_CLOEXEC|IN_NONBLOCK)`, `inotify_add_watch` with mask `IN_CREATE|IN_DELETE|IN_MODIFY|...`, then `poll`/`read` on the inotify fd to retrieve `inotify_event` records; `process::spawnAndWait` calls `fork()`, child `execvp` the executable, parent `waitpid`; `timer::setDeadline` calls `timer_create(CLOCK_MONOTONIC, &sev, &timer_id)` + `timer_settime`; debugger `outputDebug` writes to `STDERR_FILENO`; `currentThreadId` calls `::syscall(SYS_gettid)`; thread naming uses `prctl(PR_SET_NAME, ...)`; transcoding loops over bytes manually (char overload is a bounded `memcpy`).

## Integration
Consumed by `engine.core` via the `Core.HAL.cppm` umbrella export `export namespace hal { ... }`. The platform is selected at CMake configure time via `PPR_HAL_PLATFORM` (set to `linux`), which causes CMake to link the appropriate `Core.HAL.linux` module. All engine modules import `engine.core:hal` to use `pP::hal::pageAlloc`, `pP::hal::currentExecutablePath`, `pP::hal::io::poll`, etc. The runtime selects the correct implementation at link time; only the chosen platform's object files are included in the build. Linux HAL files are compiled with `-DPPR_HAL_PLATFORM=linux` and link against libc, libpthread, and libdl.

## Key Files
- `Core.HAL.linux.Memory.cpp` — mmap/munmap/mprotect page allocation with Windows-matching over-alignment, MADV_DONTNEED/FREE
- `Core.HAL.linux.RingBuffer.cpp` — memfd_create + ftruncate + PROT_NONE reservation + dual MAP_FIXED shared views
- `Core.HAL.linux.Random.cpp` — `random_device`/`seed_seq`-seeded `mt19937_64`
- `Core.HAL.linux.Io.cpp` — raw-syscall io_uring backend (setup/ring mmaps/eventfd, submit/poll/wait/wake/async-cancel, ordered teardown)
- `Core.HAL.linux.Filesystem.cpp` — HOME/XDG env vars, /proc / /usr/bin directory resolution
- `Core.HAL.linux.Process.cpp` — fork+execvp, /proc/self/exe for executable path
- `Core.HAL.linux.Timer.cpp` — timer_create/timer_settime with SIGEV_THREAD + `std23::move_only_function` callback
- `Core.HAL.linux.Debugger.cpp` — SIGTRAP, write to stderr, syscall SYS_gettid, prctl PR_SET_NAME (no POSIX `native::char_t` overload)
- `Core.HAL.linux.Strings.cpp` — manual UTF-8/ASCII transcoding + shared `string_view → char*` overload, no OS API calls
- `Core.HAL.linux.IoWatch.cpp` — inotify_init1 + inotify_add_watch + poll/read for directory events
- `Core.HAL.linux.System.cpp` — platformName "linux", userName via getpwuid/ENV
- `Core.HAL.linux.IoMap.cpp` — mmap + munmap for memory-mapped files
